Manual sync

Connects teacher accounts and question reviews

Sync exchanges teacher accounts and password changes, downloads new submissions, and sends review decisions. If one teacher's account changed independently in both places, it is flagged below rather than silently overwriting a password. Sync never publishes an exam.

Online portal administrator

Set or reset the separate login for online review

This account lets you review submissions while the school server is offline. Use a unique password of at least 12 characters. The online admin password is stored as a password hash; the local app sends it securely to the portal and does not save the plain password.

Reset a teacher's password

For a teacher already synchronized to the local server, this changes the password locally and online. If the portal cannot be reached, the local password is saved and will sync on the next successful sync. Share the temporary password privately; the teacher should change it after signing in.
